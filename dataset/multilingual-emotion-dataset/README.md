This dataset provides a multilingual benchmark for emotion classification across 13 emotional categories in both English and Hindi. It is designed to support NLP research, transformer fine-tuning, and emotion-aware conversational AI systems.

## Features
- 13 emotion labels
- Hindi + English text samples
- Balanced and class-imbalanced versions
- Multi-source metadata (Twitter, Reddit, Reviews, News)
- Train / Validation / Test splits

## Use Cases
- Multilingual sentiment and emotion classification
- BERT, RoBERTa, DistilBERT fine-tuning
- LoRA / QLoRA LLM adaptation
- Class imbalance and robustness research

## Format
Each CSV file contains:
- id
- text
- emotion
- language
- source
- topic
